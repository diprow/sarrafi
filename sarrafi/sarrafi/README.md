# دفتر حساب صرافی

نسخه‌ی مستقل دفتر حساب، برای GitHub Pages، با ورود از طریق Supabase و رمزنگاری سرتاسری.

## راه‌اندازی

1. یک repository جدید در GitHub بسازید و **همه‌ی فایل‌ها و پوشه‌ها** را آپلود کنید (پوشه‌ی `vendor` هم لازم است).
2. در repository بروید به **Settings → Pages**، و در بخش Source گزینه‌ی **Deploy from a branch** با شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کنید.
3. در داشبورد Supabase، پروژه‌ی **diaprod-site**، بروید به **Authentication → URL Configuration** و آدرس سایت GitHub Pages را (مثلاً `https://USERNAME.github.io/REPO/`) به **Redirect URLs** اضافه کنید.
4. سایت را باز کنید و با ایمیلی که در جدول `admins` سایت هست وارد شوید (یا با همان ایمیل حساب بسازید و ایمیل را تأیید کنید). **اولین مدیری که وارد شود صاحب دفتر می‌شود** و بعد از آن هیچ حساب دیگری دسترسی ندارد.
5. یک «رمز دفتر» جدا از رمز ورود بسازید. این رمز قابل بازیابی نیست.

## امنیت

- همه‌ی اطلاعات قبل از ارسال، در مرورگر با AES-256-GCM رمزنگاری می‌شود (کلید از رمز دفتر با PBKDF2-SHA256، ۶۰۰ هزار تکرار). دیتابیس فقط متن رمزشده می‌بیند.
- جدول‌ها با Row Level Security قفل‌اند: بازدیدکننده‌ی بدون ورود هیچ دسترسی ندارد، و کاربرهای دیگر سایت هم دفتر را نمی‌بینند.
- کتابخانه‌ی Supabase داخل خود repo است (بدون CDN) و با Subresource Integrity و Content-Security-Policy بارگذاری می‌شود.
- نشست ورود فقط تا بسته شدن تب می‌ماند؛ دفتر بعد از ۱۰ دقیقه بی‌کاری قفل می‌شود.
- کلید `config.js` کلید عمومی (publishable) است و قرار است عمومی باشد؛ مشکلی ندارد اگر repository عمومی باشد.

## انتقال اطلاعات از نسخه‌ی Claude

در نسخه‌ی قبلی «خروجی اکسل (CSV)» بگیرید و اینجا با دکمه‌ی «ورود از CSV» واردش کنید.
